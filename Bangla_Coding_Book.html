১. কোডিং কী?

কোডিং হলো কম্পিউটার বা ব্রাউজারকে নির্দিষ্ট কাজ করার নির্দেশ লেখা। ওয়েবসাইট বানাতে সাধারণত তিনটি জিনিস কাজে লাগে:

  • HTML: ওয়েবপেজের কাঠামো তৈরি করে—শিরোনাম, লেখা, ছবি, বাটন।
  • CSS: ওয়েবপেজকে সুন্দর করে—রং, সাইজ, দূরত্ব, বর্ডার, অবস্থান।
  • JavaScript: ওয়েবপেজে কাজ করায়—বাটনে ক্লিক, হিসাব, মেনু খোলা ইত্যাদি।
এই বইয়ে HTML ও CSS-এর ভিত্তি এবং দরকারি CSS Property-গুলো বাংলায় বোঝানো হয়েছে।

HTML ও CSS একসঙ্গে

<h1>আমার ওয়েবসাইট</h1>
<p>এটি একটি অনুচ্ছেদ।</p>
h1 {
  color: blue;
  text-align: center;
}

২. কোডিংয়ের চিহ্নগুলোর নাম

চিহ্নবাংলা নাম / পরিচিত নামকাজ
< >অ্যাঙ্গেল ব্র্যাকেট / কৌণিক বন্ধনীHTML ট্যাগ শুরু ও শেষ করে।

( )প্যারেনথেসিস / প্রথম বন্ধনীফাংশন বা কিছু মানের অংশ ঘিরে রাখে।

.ডট / বিন্দুCSS Class বোঝায়: .box

*অ্যাস্টেরিস্ক / তারকাসব HTML Element নির্বাচন করে।

' 'সিঙ্গেল কোটেশনডাবল কোটেশনের বিকল্প।

_আন্ডারস্কোরনামের মাঝে ফাঁকা স্থানের বিকল্প হিসেবে ব্যবহৃত হতে পারে।
-হাইফেন / বিয়োগ চিহ্নCSS-এর যৌগিক নামে ব্যবহৃত হয়: font-size

&অ্যাম্পারস্যান্ডHTML Entity বা CSS nesting-এ দেখা যায়।

৩. দরকারি HTML ট্যাগ

ট্যাগকাজ
<!DOCTYPE html>ব্রাউজারকে জানায় এটি HTML5 ডকুমেন্ট।

৪. CSS কী? CSS লেখার নিয়ম

CSS-এর পূর্ণরূপ Cascading Style Sheets। এটি HTML Element-এর চেহারা নিয়ন্ত্রণ করে।

selector {
  property: value;
}
  • Selector: কোন Element সাজাবেন।
  • Property: কোন বিষয় বদলাবেন।
  • Value: কী মান দেবেন।

উদাহরণ:

p {
  color: red;
  font-size: 18px;
}

এখানে p হলো Selector, color ও font-size হলো Property, আর red ও 18px হলো Value।

CSS কোথায় লিখবেন?

১. Internal CSS: HTML-এর <head>-এর ভেতরে <style> ট্যাগে।

<style>
  body { background: #f0f0f0; }
</style>

২. External CSS: আলাদা style.css ফাইলে লিখে HTML-এ যুক্ত করুন:

<link rel="stylesheet" href="style.css">

৩. Inline CSS: HTML ট্যাগের style Attribute-এ সরাসরি লিখুন।

<p style="color: blue;">নীল লেখা</p>

৫. Margin, Padding, Border ও গোল কোণা

একটি Box-এর চারপাশের দূরত্ব ও বর্ডার বোঝার জন্য এই অংশটি সবচেয়ে গুরুত্বপূর্ণ।

Margin — বাইরের ফাঁকা জায়গা
Content
Padding হলো Content ও Border-এর মাঝের ভেতরের ফাঁকা জায়গা।
CSS Propertyবাংলায় কাজউদাহরণ
marginElement-এর বাইরের ফাঁকা জায়গা।margin: 20px;
paddingElement-এর ভেতরের ফাঁকা জায়গা।padding: 15px;
borderElement-এর চারপাশে বর্ডার/সীমানা।border: 2px solid red;
border-radiusবর্ডারের কোণা গোল করে।border-radius: 15px;
border-widthবর্ডার মোটা বা চিকন করে।border-width: 1px;
border-styleবর্ডারের ধরন ঠিক করে।border-style: dashed;
border-colorবর্ডারের রং ঠিক করে।border-color: blue;
box-shadowবক্সের চারপাশে ছায়া দেয়।box-shadow: 0 4px 12px #0003;
outlineবর্ডারের বাইরে অতিরিক্ত রেখা দেয়।outline: 2px solid green;

বর্ডার গোল করবেন কীভাবে?

.box {
  border: 2px solid #3157d5;
  border-radius: 20px;
}

বর্ডার ছোট বা চিকন করবেন কীভাবে?

border-width কমিয়ে দিন। যেমন ৫px থেকে ১px করলে বর্ডার চিকন হবে।

.box {
  border-style: solid;
  border-width: 1px;
  border-color: #333;
}

শুধু এক পাশের বর্ডার

border-top: 2px solid red;
border-right: 2px solid blue;
border-bottom: 2px solid green;
border-left: 2px solid orange;

Margin ও Padding-এর চার পাশ আলাদা

margin: 10px 20px 30px 40px;
/* উপর, ডান, নিচ, বাম */

padding: 10px 20px;
/* উপর-নিচ 10px, ডান-বাম 20px */

সব কোণা একরকম না করে আলাদা করতে পারেন:

border-radius: 20px 5px 20px 5px;
/* উপর-বাম, উপর-ডান, নিচ-ডান, নিচ-বাম */

১০. বাটন, Hover ও Animation

সুন্দর বাটন

.my-button {
  background: #3157d5;
  color: white;
  border: none;
  padding: 12px 22px;
  border-radius: 12px;
  cursor: pointer;
  transition: .3s;
}
.my-button:hover {
  background: #19368f;
  transform: translateY(-2px);
}

Hover মানে মাউস বাটনের ওপর নিলে যে পরিবর্তন হয়। মোবাইলে Hover সব সময় একইভাবে কাজ নাও করতে পারে।

দরকারি Property

Propertyকাজ
cursorমাউস পয়েন্টারের ধরন বদলায়।
transitionপরিবর্তন মসৃণ করে।
transformElement সরায়, ঘোরায় বা বড়-ছোট করে।
animationঅ্যানিমেশন চালায়।
filterBlur, brightness ইত্যাদি প্রভাব দেয়।
@keyframes pulse {
  0% { transform: scale(1); }
  50% { transform: scale(1.05); }
  100% { transform: scale(1); }
}

  animation: pulse 2s infinite;
}

১২. CSS Selector—কোন Element নির্বাচন করবেন?

Selectorকাজউদাহরণ
pসব Paragraph নির্বাচন।p { color: red; }
.boxbox Class-যুক্ত Element।.box { padding: 10px; }
#headerheader ID-যুক্ত Element।#header { height: 60px; }
*সব Element।* { box-sizing: border-box; }
div pdiv-এর ভেতরের সব p।div p { color: blue; }
button:hoverমাউস নিলে বাটন।button:hover { opacity: .8; }
input:focusInput-এ ফোকাস থাকলে।input:focus { border-color: blue; }
h1, h2h1 ও h2 দুটিই নির্বাচন।h1, h2 { color: navy; }

১৩. অনুশীলন: একটি সুন্দর কার্ড তৈরি

নিচের কোডটি একটি HTML ফাইলে কপি করে ব্রাউজারে খুললে গোল বর্ডার, ছায়া ও বাটনসহ একটি কার্ড দেখা যাবে।

১৪. ছোট শব্দকোষ ও মনে রাখার নিয়ম

ইংরেজি শব্দবাংলা অর্থ
ElementHTML-এর একটি উপাদান।
TagHTML-এর নির্দেশক চিহ্ন, যেমন <p>।
Attributeট্যাগের অতিরিক্ত তথ্য, যেমন href, src।
SelectorCSS দিয়ে যাকে নির্বাচন করা হয়।
Propertyযে বৈশিষ্ট্য বদলাবেন।
ValueProperty-তে দেওয়া মান।
Responsiveমোবাইল, ট্যাব ও কম্পিউটারে মানিয়ে যায়।
Viewportব্রাউজারে বর্তমানে দেখা যায় এমন অংশ।
Debuggingকোডের ভুল খুঁজে ঠিক করা।

দ্রুত মনে রাখুন

  • লেখার রং বদলাতে: color
  • বক্সের পেছনের রং বদলাতে: background-color
  • বক্স গোল করতে: border-radius
  • বর্ডার চিকন করতে: border-width
  • বক্সের বাইরের ফাঁকা: margin
  • বক্সের ভেতরের ফাঁকা: padding
  • বক্সের প্রস্থ: width
  • বক্সের উচ্চতা: height
  • লেখা মাঝখানে: text-align: center
  • বক্স মাঝখানে: Flexbox-এর justify-content ও align-items
মনে রাখবেন: CSS-এর সব Property সব Element-এ একইভাবে কাজ করে না। কোড লেখার পর ব্রাউজারে পরীক্ষা করুন। ভুল হলে কোলন :, সেমিকোলন ; এবং কার্লি ব্রেস { } ঠিক আছে কি না দেখুন।
